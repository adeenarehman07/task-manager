# Task Manager

A simple task manager web app built with HTML, CSS and vanilla JavaScript.

## Features
- Add, complete and delete tasks
- Filter by All / Active / Done
- Tasks are saved in the browser (localStorage)
- Responsive layout

## How to use
Open the live demo from the link in the repository's About section (top right of this page), or download `index.html` and open it in any browser.

## Technologies
HTML5, CSS3, JavaScript (ES6)
